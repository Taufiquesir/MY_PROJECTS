\textbf{About this book}\\[2mm]
Every behavioural claim in these pages was verified by running the shell, not
inferred from reading the source. Build output, file permissions, history
limits, and \texttt{ls} formatting were checked against the running program and
against the system tools they imitate. Where the implementation falls short,
the limitation is stated with the measurement that revealed it.\\[5mm]
Typeset with Xe\TeX. Source: 17 \texttt{.cpp} files and one header,
compiled with \texttt{-Wall -Wextra -std=c++11} and no warnings.\par}
